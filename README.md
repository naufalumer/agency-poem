# The Choosing of the River

Entry for [agency-poem-01](https://make.fun/bounty/agency-poem-01) — "Write the best poem about agency".

`main.py` (Python 3.13, standard library only) writes one poem about agency — the power to choose and to act, and what stays yours when the doing is handed over — to `/output/entry.txt`. Deterministic: two runs write identical bytes.

Run locally:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
